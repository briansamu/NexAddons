## What it does

---

Nex Addons is a Fabric Minecraft mod that will add useful features to <a href="https://wiki.hypixel.net/Main_Page" style="text-decoration: underline">Hypixel Skyblock</a>. With NexAddons you have access to:

- **Nothing:** No features to see yet!

## Getting Started

---

1. **Install:** Put the jar in your mods folder.
2. **Set Up:** Type ```/na``` or ```/nexaddons``` in-game to configure your settings.
3. **Explore:** Find what features will help you most.
